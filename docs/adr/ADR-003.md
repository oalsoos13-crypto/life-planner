# ADR-003: المؤشر كيان مستقل `Metric`

**الحالة:** مقبول (20 نوفمبر 2026)

## السياق
المؤشر كان مدفون بحقول `Goal.kpi*`، والمنهجية بتستخدمه بـ 4 أماكن (نتيجة رئيسية، هدف صيانة، هدف استراتيجي، عادة).

## القرار
جدول `Metric` (مالك واحد: هدف دورة أو هدف استراتيجي) و`MetricReading (metricId, date)`. الترحيل بنمط وسّع ← حوّل ← قلّص؛ الحقول القديمة لسا موجودة لخطوة «قلّص».

## العواقب
(+) مفهوم واحد بمكان واحد. (−) فترة انتقالية فيها نسختين.

## الالتزام (كيف بنتأكد إنه ماشي)
migration `phase2_strategy_core` بينسخ القديم؛ اختبار ترقية النسخ v1.

**المصدر:** Domain-Driven Design، Pragmatic Programmer (DRY)، Refactoring Databases
