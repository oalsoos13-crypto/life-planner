# ADR-005: القواعد الحرجة بقيود بقاعدة البيانات + الكود؛ التنبيهات بالكود بس

**الحالة:** مقبول (20 نوفمبر 2026)

## السياق
«حد 3 OKRs» ممكن ينكسر بسباق بين تابين (انحراف الكتابة).

## القرار
`@@unique([cycleId, rank])` + CHECK على الرتبة والنوع والوزن والساعات وطول التحدي ومالك المؤشر. فحوصات «الاستراتيجية السيئة» تنبيهات ناعمة بالمجال.

## العواقب
(+) القاعدة آخر خط دفاع. (−) رسالة خطأ القاعدة لازم تترجم بالكود.

## الالتزام (كيف بنتأكد إنه ماشي)
اختبار تكامل بيحاول يتجاوز الكود.

**المصدر:** Designing Data-Intensive Applications، Domain-Driven Design
