# ADR-001: مونوليث معياري واحد مقسّم حسب مراحل المنهجية

**الحالة:** مقبول (20 نوفمبر 2026)

## السياق
المرحلة 2 بتضيف حوالي 25 مفهوم. مستخدم واحد وأقل من 10 آلاف صف بالسنة.

## القرار
تطبيق Next.js واحد وقاعدة وحدة، والكود بـ `src/modules/` لخمس وحدات: direction، diagnosis، strategy، execution، measurement. الاعتماد باتجاه واحد: measurement ← execution ← strategy ← diagnosis ← direction.

## العواقب
(+) كل ميزة بمكان واحد، بسيط للنشر. (−) حدود بالانضباط مش بالشبكة.

## الالتزام (كيف بنتأكد إنه ماشي)
قواعد ESLint بـ `eslint.config.mjs`.

**المصدر:** Fundamentals of Software Architecture، Head First Software Architecture
