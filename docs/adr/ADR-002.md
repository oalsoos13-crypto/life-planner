# ADR-002: قاعدة الاعتمادية: المجال نقي، الكتابة عبر حالات الاستخدام، القراءة مباشرة

**الحالة:** مقبول (20 نوفمبر 2026)

## السياق
`actions.ts` كان خالط الدخول والكوكيز وPrisma والقواعد، فما بينختبر بدون قاعدة.

## القرار
`domain/` دوال نقية (ما بتستورد Prisma ولا Next ولا React، والوقت بينمرق لها). `application/` حالات استخدام بمعاملات. Server Actions رفيعة. الصفحات بتقرأ من `queries.ts` مباشرة (حد جزئي).

## العواقب
(+) القواعد بتنختبر بالآلاف بثواني. (−) طبقة زيادة صغيرة.

## الالتزام (كيف بنتأكد إنه ماشي)
ESLint `no-restricted-imports` على `domain/`.

**المصدر:** Clean Architecture
