# ADR-007: القراءات وسجل العادات «إضافة وتعديل بس»

**الحالة:** مقبول (20 نوفمبر 2026)

## السياق
التاريخ هو الي بيعطي معنى للمراجعة.

## القرار
قراءة وحدة لكل مؤشر بكل تاريخ (`@@id([metricId, date])`)، والتسجيل upsert.

## العواقب
(+) تاريخ نظيف. (−) لتصحيح خطأ بتعدّل القراءة مش بتحذفها.

## الالتزام (كيف بنتأكد إنه ماشي)
المفتاح المركّب.

**المصدر:** Designing Data-Intensive Applications
