# ADR-004: OKR = `Goal` بـ `kind = OKR` بدل جدول جديد

**الحالة:** مقبول (20 نوفمبر 2026)

## السياق
المهام الأسبوعية والخطة والتكرار كلها مربوطة بـ `goalId`.

## القرار
`Goal.kind` (OKR/صيانة)، `rank` 1..3، `okrType`، `strategicGoalId`، `weeklyHours`. الترقية والتنزيل بدون ما ينكسر أي ربط.

## العواقب
(+) ولا رابط بينعاد. (−) حقول بتنطبق على OKR بس.

## الالتزام (كيف بنتأكد إنه ماشي)
اختبار تكامل الترقية والتنزيل.

**المصدر:** Software Architecture: The Hard Parts (تحليل المقايضة)
