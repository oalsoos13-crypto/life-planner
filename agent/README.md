# وكيل خطتي على اللابتوب

التطبيق بيرتّب المهام والموافقات. الشغل نفسه بيصير على لابتوبك بـ **Claude Code**، جوّا مجلد شغلك:
تقارير Excel، ومسودات إيميل، وترتيب ملفات. **ملفات الشركة ما بتطلع من اللابتوب.**
التطبيق بيشوف بس عنوان المهمة وحالتها وملخّص قصير، وأي رقم بالملخّص بينشال قبل ما ينحفظ.

## الإعداد (مرة وحدة، 10 دقايق)

1. نزّل **Node.js 20+** و **Claude Code**، وسجّل دخول بحسابك (`claude` بالـ Terminal).
2. اعمل توكن سرّي طويل (32 حرف أو أكتر). مثلاً: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`.
3. بـ Vercel، بإعدادات المشروع، Environment Variables، زيد `AGENT_TOKEN` بقيمة التوكن، وبعدين Redeploy.
4. على اللابتوب، شغّل الأوامر هاي (PowerShell):

   ```powershell
   $env:LP_URL = "https://<رابط-تطبيقك>"
   $env:LP_AGENT_TOKEN = "<نفس التوكن>"
   $env:WORK_ROOT = "C:\Users\<اسمك>\Documents\Work"
   node agent\run.mjs
   ```

5. افتح «وكيلك على اللابتوب» بالتطبيق. لازم تشوف «اللابتوب شغّال».

لتشغيله لحاله مع ويندوز: Task Scheduler، «At log on»، ونفس الأمر.

## كيف بيشتغل

1. إنت بتطلب من التطبيق، مثلاً «تقرير المبيعات الأسبوعي كل أحد».
2. الوكيل بيحضّر الملف ومسودة الإيميل على اللابتوب، **وما بيبعت**.
3. بيوصلك بالتطبيق «بيستنى موافقتك». بتكبس **ابعت** أو **لا تبعت**.
4. بس بعد موافقتك بيبعت نفس المسودة بالضبط.

**الإذن الدائم:** للتقارير الأسبوعية بس. بيبعت لحاله، وبتقدر تشيله أي وقت.

## الأمان

- الوكيل ما بيطلع برّا `WORK_ROOT`، وما بيحذف ولا بيكتب فوق ملف أصلي.
- التوكن بـ Vercel وعلى لابتوبك بس. لا تحطه بالكود ولا تبعته لحدا.
- إذا اللابتوب انطفى بنص مهمة، بترجع للدور بعد ساعة.
